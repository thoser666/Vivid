The Java capture library is distributed under Apache License 2.0.
Bundled native components include libusb (LGPL 2.1 or later), libuvc
(BSD), libjpeg-turbo (IJG/BSD/zlib), libyuv (BSD) and RapidJSON (MIT/BSD).
License texts are included in this directory. The libyuv LICENSE,
PATENTS and AUTHORS files are from the upstream libyuv mirror at
https://github.com/lemenkov/libyuv; UVCAndroid's source snapshot omits them.

This software is based in part on the work of the Independent JPEG Group.

Vivid uses the AAR shared native libraries without modifications and does
not use the SDK recording or storage helpers. No native library source
is copied into Vivid. Vivid's capture adapter is separate Kotlin code.
